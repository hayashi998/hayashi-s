# 钓钓乐 · 手机浏览器 Demo

零构建、无第三方网络依赖的静态 H5。场景使用 CSS 和系统 emoji，未接虎扑账号或资产接口。

## 启动

在本目录运行：

```sh
python3 -m http.server 8765 --bind 0.0.0.0
```

电脑打开 http://localhost:8765 。手机与电脑连接同一 Wi-Fi，用电脑局域网 IP 加端口 8765 访问；电脑需保持服务运行。没有发布公网地址。

## 已实现规则

- 初始 10,000 珍珠，档位 100 / 1,000 / 10,000。
- 20 秒下注，多鱼投入、重复加注，单鱼全部撤回并退款。
- 封盘后禁止变更，5 秒开奖，唯一结果，2 秒展示后自动下一局。
- 倍率 100 / 50 / 25 / 11 / 7 / 4 / 2，到账包含本金。
- 七种鱼等概率，各 1/7；game.mjs 的 WEIGHTS 可调整相对权重。
- 充值入口为演示占位，付费模拟 +10,000、广告模拟 +1,000，不连接真实服务。
- 余额和历史保存在当前页面内存，刷新重新开始。
- 后台切回按时间结算已投入的一局，不重复结算，不追赶空闲轮次。

## 文件

- index.html / style.css：布局和基础海湾动画。
- app.mjs：UI、充值弹窗、结果与历史展示。
- game.mjs：状态、计时、随机结果和结算。
- game.test.mjs：核心规则自动化测试，运行 `node --test game.test.mjs`。

## 验收

自动化覆盖：多鱼加注、余额不足、单鱼撤回、20 秒边界封盘、5 秒后结算、2 秒后下一局、含本金计算、避免重复结算、七个随机区间、后台恢复。
浏览器人工检查：390 和 360 像素视口、投入/撤回、两个模拟到账入口。计时与完整开奖周期由自动化测试验证。
